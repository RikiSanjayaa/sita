# Peta pemeriksaan PR #192

PR: https://github.com/RikiSanjayaa/sita/pull/192

Pembaruan 8 November 2026. Lima paket utama sudah diterapkan. Review pada `84158aa4` menutup delapan dari tiga belas percakapan berdasarkan kode dan bukti PR. Lima percakapan lain memiliki kriteria tambahan. Penerimaan reviewer/fakultas tetap terpisah dari kelulusan tes; agent tidak menutup percakapan atas nama reviewer.

## Keputusan kerja terbaru

- Daftar Admin dan detail Dosen hanya menawarkan cetak dan Word ketika template tersedia. Admin tetap dapat membuka Berkas Sidang dan memasukkan nilai jika panel memenuhi syarat. Ketersediaan template dan kelengkapan panel diperiksa terpisah.
- Pemilik produk belum menanyakan bobot panel satu penguji dan dua pembimbing ke kampus. Tidak ada peran atau bobot yang dikarang. Ekspor sekarang menyebut nama, NIM, dan attempt yang terhalang. File campuran dibatalkan dengan 422, bukan kehilangan mahasiswa diam-diam. Pilihan data lain yang valid dapat diekspor secara eksplisit.
- Pola UI sekarang dipertahankan: satu nama contoh pada kartu utama Kaprodi, angka seluruh antrean, tautan menuju seluruh hasil terfilter, serta breadcrumb ringkas dari renderer global. Nama/NIM/attempt tetap tampil pada identitas Berkas Sidang. Tidak ada pengecualian desain satu halaman.
- Setelah pemilik produk meminta pendekatan terbaik, rekomendasi teknisnya tetap XML bertahap untuk menjaga template Excel. Bukti volume, rumus, merge dan area cetak menjadi bahan penerimaan maintainer terhadap #23. Requirement issue tidak diubah sepihak. Dependency langsung OpenSpout belum dihapus karena perubahan dependency memerlukan persetujuan eksplisit.
- Teks tetap formulir mengikuti contoh fakultas sampai ada pengganti resmi. Penerimaan fakultas masih diperlukan. Kebijakan koreksi No SK setelah final belum diubah: individual sebelum final; massal tidak menimpa nomor berbeda.

## Pemeriksaan manual

1. Admin: menu Rekap tetap ada saat berpindah tab; Atur Periode Rekap dan Ekspor Rekap Nilai memakai scope/filter prodi yang benar.
2. Berkas Sidang: periksa baris terjadwal, menunggu finalisasi, selesai; ikon cetak/Word berada pada slot sama dan aksi utama sesuai status.
3. Edit dosen: simpan NIDN sendiri, lalu coba milik dosen lain. Error dekat field, draf tetap ada; beberapa NIDN kosong tetap sah.
4. Detail tugas akhir selesai tanpa pembimbing aktif: Fokus Saat Ini menjelaskan selesai. Periksa juga arsip dan batal.
5. Di dua portal: ekspor periode/rentang, proses, gagal/kosong, sukses, serta pesan mahasiswa panel lama tanpa file parsial.
6. Periksa sembilan lembar sebelum/sesudah finalisasi terhadap contoh fakultas. Setujui teks tetap atau berikan pengganti resmi.

Commit, hasil uji/CI, screenshot dan revisi deployment terbaru dicatat di pembaruan PR. #17/#23 dan percakapan yang menunggu keputusan tidak ditutup otomatis.
