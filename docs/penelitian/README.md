# Catatan Penelitian yang Menggunakan SITA

SITA dapat digunakan sebagai aplikasi target untuk penelitian terkait otomatisasi *deployment* atau autentikasi *workload*. Repository ini menyimpan kode aplikasi SITA dan dokumentasi operasional umum saja.

Artefak eksperimen, data mentah, konfigurasi laboratorium, akun, alamat infrastruktur, serta dokumen akademik pribadi tidak disimpan di sini. Setiap penelitian harus menggunakan repository dan lingkungan laboratorium terpisah, kemudian hanya menyimpan rujukan, metode yang telah disetujui, dan hasil yang telah dianonimkan bila memang perlu dipublikasikan.

## Batasan dokumentasi

- Dokumentasi aplikasi yang stabil tetap berada di `README.md` dan `docs/`.
- Catatan eksperimen sementara dan hasil keluaran generator dokumen diabaikan oleh Git.
- Perubahan kode aplikasi harus memiliki alasan fungsional dan pengujian yang relevan, terlepas dari kebutuhan penelitian yang menggunakan SITA sebagai studi kasus.
